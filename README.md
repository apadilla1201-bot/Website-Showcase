# Website-Showcase

## Meridian Private Aviation (built with the 10k-websites skill)

`meridian/` is a complete static site: `index.html` plus `assets/`. No build step.

- Double-click `meridian/index.html` to see the designed still-image hero (browsers block the video fetch on file:// on purpose).
- For the full scroll-scrubbed hero, serve the folder: `cd meridian && npx http-server -p 8080` then open http://localhost:8080.
- `meridian-design-package.md` holds every creative decision and the verbatim copy.
